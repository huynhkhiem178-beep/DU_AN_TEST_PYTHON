# Bài làm đề 01

Đặt file Python bài làm tại thư mục này, ví dụ `bai_lam.py`.

Chạy chấm điểm từ thư mục gốc dự án:

```powershell
py -m autograder.grade submissions/de1/bai_lam.py --student-id SV001
```

File bài làm cần cung cấp các hàm/lớp có tên và tham số tương ứng với
`src/exam_tasks.py`. Bộ chấm hiện tại kiểm tra kết quả trả về của hàm,
không đọc nội dung được in ra màn hình.
